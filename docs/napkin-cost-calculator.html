Raw Cost Estimator — napkin-math

A hardware-floor estimate: size RAM & disk the same way Qdrant does, then price the raw resources at napkin-math unit rates (CPU $15, RAM $2/GB, SSD $0.2/GB per month). No vendor margin, no fixed node tiers — just CPU + RAM + disk. CPU is the rough input: it dominates the total and depends on your query load, so treat the default as a placeholder.

Model: RAM = vectors × dim × 4 B × 1.5 ÷ quantization ÷ 10⁹ (same as the Qdrant capacity planner); disk = RAM (+ quantized copy). Cost = replicas × (vCPU × CPU-rate + RAM × mem-rate + disk × disk-rate). Rates from sirupsen/napkin-math "Cost Numbers" (rounded, cross-provider). This is a margin-free hardware floor — a managed service (Qdrant Cloud) charges more for the same shape. The vCPU figure is a rough provisioning placeholder (default ≈1 vCPU per 4 GB RAM, min 1); real vector-search CPU tracks query load (QPS × per-query work) and recall/ef, so refine it for your workload.

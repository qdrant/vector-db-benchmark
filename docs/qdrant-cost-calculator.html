Model & pricing distilled from the qdrant-cloud-ui Calculator source (AWS eu-central packages). Estimate only — confirm against the official calculator.

Model (from qdrant-cloud-ui): base RAM = vectors × dim × 4 B × 1.5 (metadata/optimization overhead) ÷ 10⁹, then ÷ quantization divider, then × replicas. Required disk = base RAM (+ quantized copy when quantization is on). The cheapest package whose RAM × nodes ≥ required RAM is chosen (min 3 nodes when replicas > 1, preferring fewer nodes within 1.15× of the cheapest price). Pricing: $/mo = unitPricePerHour ÷ 100000 × 24 × 30.5; extra disk at $72 (millicents)/GB-hr. Constants and package prices are AWS eu-central-1 as of the source snapshot — other regions/providers differ.
